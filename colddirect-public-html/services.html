How a call-out works

Call with the fault, postcode and a photo of the data plate if you have one. We give a realistic attendance window. On site we diagnose, quote the repair before we start a long job, and tell you if a part has to be ordered. Common Williams, Foster, Polar, Blizzard and Gram parts travel with the van.

Servicing between emergencies

Where sites want planned visits, we service condensers, door furniture and probes so Saturday breakdowns are less likely and temperature logs stay clean for the EHO. Emergency repair still runs 24/7 when plant has already climbed.
