# پایش وضعیت ایندکس ColdDirect

این بررسی با دسترسی موجود Search Console و به‌صورت فقط‌خواندنی انجام می‌شود. نقشهٔ زنده خوانده می‌شود و وضعیت آدرس‌های آن از گوگل دریافت می‌شود. گزارش‌های کامل در reports/gsc-monitor نگهداری می‌شوند.

هدف، شناسایی ایندکس‌شدن صفحهٔ خدمات، تغییر وضعیت سایر صفحات و خطاهای نقشه یا اتصال است. تغییر معمولِ تاریخ خزش هشدار ایجاد نمی‌کند. وضعیت ایندکس با رتبهٔ جستجو برابر نیست.

در صورت اجرای ناقص، گزارش مبنای آخرین اجرای کامل حفظ می‌شود. کلیدها و توکن‌ها در گزارش یا Git ثبت نمی‌شوند. برنامه هیچ درخواست Google Indexing API، تغییر سایت، ادغام یا انتشار انجام نمی‌دهد.

اجرای محلی به روشن‌بودن رایانه، بازبودن برنامه و دسترسی مجاز شبکه نیاز دارد. موفقیت آزمون دستی، موفقیت اجرای زمان‌بندی‌شدهٔ بعدی را از قبل اثبات نمی‌کند.

محدودیت فعلی: حداکثر ۲۰۰ آدرس در هر اجرا؛ اگر نقشه بزرگ‌تر شود، برنامه برای بازبینی متوقف می‌شود. چهار اتصال مستقل با سقف انتظار ۳۰ ثانیه برای هر درخواست استفاده می‌شود.

اسکریپت‌های قدیمی درخواست انبوه ایندکس برای صفحات تعمیرات اجرا نمی‌شوند. گوگل نقشهٔ ثبت‌شده را دوره‌ای پردازش می‌کند؛ پایش حاضر وضعیت پردازش را بررسی می‌کند و ایندکس‌شدن را تضمین نمی‌کند.
